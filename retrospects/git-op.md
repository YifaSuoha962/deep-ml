### 提交报错

--rebase 的含义是：拉取远程更新后，把你本地尚未推送的提交“重新接到”远程最新提交之后，而不是生成一条额外的合并提交。

  例如：

  远程 main：A — B — C
  本地 main：A — B — D — E

  执行：

  git pull --rebase origin main

  Git 会先取得远程的 C，暂时取下你的 D、E，然后变成：

  A — B — C — D' — E'

  其中 D'、E' 内容通常和原来的 D、E 相同，但由于父提交改变了，它们是新的提交对象。

Note: 它适合处理“本地自己的、尚未推送到共享分支的提交”。不要对已经被其他人基于其开发的公共提交随意 rebase，因为它会改写提交历史。对于你本地尚未推送的提交，使用它通常是安全且推荐的。
